# سوق عُمان – تشغيل على جهازك (سيرفر داخلي)

## 1) التثبيت (مرة واحدة)
ثبّت Node.js بنسخة LTS من https://nodejs.org (يلزم الإصدار 18 أو أحدث). لا تحتاج أي أوامر أخرى ولا `npm install`.

## 2) التشغيل
- **ويندوز:** انقر مرتين على `start.bat`.
- **ماك أو لينكس:** افتح الطرفية في المجلد ونفّذ `sh start.sh`.

ستظهر نافذة فيها الروابط. اتركها مفتوحة طوال تشغيل الموقع، وأغلقها أو اضغط Ctrl+C للإيقاف.

## 3) الروابط
| | الرابط |
|---|---|
| المتجر | http://localhost:3000 |
| لوحة التحكم | http://localhost:3000/admin |
| من هاتفك على نفس الواي فاي | الرابط الذي يظهر في النافذة بعبارة «Other devices on the same Wi-Fi» |

- رمز دخول لوحة التحكم: `TARIQ123`. غيّره من ⚙️ التحكم بالموقع ← 🔐 رمز الدخول.
- ويندوز قد يسأل عن الجدار الناري: اسمح بالشبكات الخاصة حتى تفتح الأجهزة الأخرى الموقع.
- على الهاتف عبر `http://` تعمل الكاميرا بفتح تطبيق الكاميرا نفسه. المعاينة الحية داخل الصفحة تحتاج HTTPS فلا تعمل في الشبكة الداخلية.
- الموقع لا يُفتح من خارج بيتك أو مكتبك. للنشر على الإنترنت ارفعه على استضافة مثل Render.

## 4) الإعدادات
افتح `config.env` بمفكرة النصوص: المنفذ `PORT`، وجعل الموقع على هذا الجهاز فقط `HOST`، ورمز احتياطي `ADMIN_PASSWORD`، ومفتاح `ANTHROPIC_API_KEY` للتعرف على الصور. أعد التشغيل بعد أي تعديل.

## 5) أين البيانات؟
مجلد `data` ينشأ تلقائياً: `db.json` (الإعلانات والمتاجر والإعدادات) و`uploads` (الصور) و`audit.log` (سجل العمليات). انسخ هذا المجلد للنسخ الاحتياطي.

## 6) التقييم وحذف الإعلانات
- **تقييم المتاجر:** على كل بطاقة متجر زر ⭐ (مثل ⭐ 4.5 (12)). يختار الزائر من 1 إلى 5 نجوم مع تعليق اختياري، وكل جهاز له تقييم واحد لكل متجر (إعادة التقييم تحدّث القديم).
- **حذف المستخدم لإعلانه:** بعد نشر الإعلان يحفظ المتصفح مفتاح الحذف، فيظهر على إعلانه زر «🗑️ حذف إعلاني» في نفس المتصفح فقط.
- **في لوحة التحكم:** تبويب ⭐ التقييمات لحذف أي تقييم. وفي 🏪 المنشور ← الإعلانات: تحديد وحذف عدة إعلانات، أو «حذف كل الإعلانات المنشورة».
- **المفاتيح:** من ⚙️ التحكم بالموقع أطفئ «تقييم المتاجر» أو «زر حذف إعلاني»، فتختفي من الموقع ويرفضها السيرفر أيضاً.

## 7) تسجيل الدخول بجوجل
1. افتح console.cloud.google.com وأنشئ مشروعاً، ثم **APIs & Services ← OAuth consent screen** وأكمل الاسم والبريد.
2. **Credentials ← Create credentials ← OAuth client ID ← Web application**.
3. في **Authorized JavaScript origins** أضف `http://localhost:3000` ونطاق موقعك مثل `https://souq-oman.onrender.com` (بدون مسار ولا Redirect URI).
4. انسخ **Client ID** وضعه في `config.env` بالسطر `GOOGLE_CLIENT_ID=...` (أو في Environment على Render) وأعد التشغيل.
- يظهر زر «دخول» في الموقع، ومن حسابه يرى المستخدم إعلاناته ويحذفها من أي جهاز.
- جوجل لا يقبل عناوين مثل `http://192.168.x.x`، فالدخول يعمل على `localhost` أو على نطاق HTTPS فقط.
- من ⚙️ التحكم بالموقع تستطيع اشتراط تسجيل الدخول لنشر الإعلانات والتقييم، أو إخفاء زر الدخول.

## 8) الإظهار والإخفاء والترتيب
- 🏪 المنشور: تبويبا «ظاهر» و«مخفي»، مع «إخفاء الكل» و«إظهار الكل» (للمتاجر أو الإعلانات)، وإخفاء أو إظهار المحدد.
- ⚙️ التحكم بالموقع: «إظهار الكل» و«إخفاء الكل» للأزرار والأقسام، وترتيب التصنيفات بالأسهم مع إخفاء أي تصنيف، وترتيب المتاجر (الأعلى تقييماً أو الأحدث أو الاسم).
- ⭐ التقييمات: ترتيب حسب الأحدث أو الأعلى أو الأدنى.

## 9) ترتيب الملفات
```
souq-oman/
├─ start.bat        تشغيل ويندوز
├─ start.sh         تشغيل ماك/لينكس
├─ config.env       الإعدادات
├─ server.js        السيرفر
├─ public/index.html   المتجر
├─ admin/index.html    لوحة التحكم
├─ seed/shops.json     المتاجر والمنتجات الجاهزة (تُضاف أول تشغيل)
└─ data/            تُنشأ تلقائياً
```

# تقني عُمان – Tech Oman

منصة عُمانية لاكتشاف مقدمي الخدمات التقنية والبرمجية وطلبها، مع دليل للشركات والمتخصصين ولوحة تحكم لإدارة الطلبات والمحتوى.

## التشغيل محلياً
- يلزم Node.js 18 أو أحدث.
- ويندوز: شغّل `start.bat`.
- ماك أو لينكس: شغّل `sh start.sh`.
- لا توجد حاجة إلى `npm install`؛ الخادم يستخدم Node.js فقط.

## الروابط
| الصفحة | الرابط |
|---|---|
| الموقع | http://localhost:3000 |
| لوحة التحكم | http://localhost:3000/admin |

رمز الدخول الأولي للوحة التحكم: `TARIQ123`. غيّره فور أول تسجيل دخول من إعدادات لوحة التحكم. لا تستخدم الرمز الأولي على موقع عام لفترة طويلة.

## إعدادات الخادم
عدّل `config.env` أو عيّن متغيرات البيئة في منصة الاستضافة:
- `PORT`: منفذ الخادم.
- `ADMIN_PASSWORD`: رمز رئيسي احتياطي للوحة التحكم (اختياري، ويجب أن يكون 8 أحرف أو أكثر).
- `GOOGLE_CLIENT_ID`: اختياري لتفعيل تسجيل الدخول بجوجل.
- `OPENAI_API_KEY`: مفتاح OpenAI API لتشغيل معلّم البرمجة (يبقى سرياً في Render).
- `OPENAI_MODEL`: اسم نموذج API (اختياري؛ الافتراضي `gpt-6.2-astra`).
- `THAWANI_SECRET_KEY` و`THAWANI_PUBLISHABLE_KEY`: مفاتيح بوابة ثواني للتاجر.
- `THAWANI_MODE`: `test` للاختبار أو `live` للمدفوعات الحقيقية.
- `AI_TUTOR_PRICE_BAISA`: سعر اشتراك 30 يوماً بالبيسة؛ مثال `3000` يعني 3.000 ر.ع.
- `AI_TUTOR_STORAGE_READY`: اجعله `true` فقط بعد تركيب Persistent Disk أو قاعدة بيانات دائمة لحفظ الاشتراكات والمدفوعات.
- `PUBLIC_BASE_URL`: عنوان الموقع العام (اختياري؛ الافتراضي `https://souq-oman.onrender.com`).

### معلّم البرمجة بالذكاء الاصطناعي
يتطلب القسم حساب Google موثّقاً، ومفتاح `OPENAI_API_KEY`، وحساب تاجر مفعّلاً لدى ثواني مع مفاتيح API. الاشتراك الحالي دفعة واحدة لمدة 30 يوماً دون تجديد تلقائي. ينشئ الخادم جلسة الدفع ويتحقق من `payment_status` والمبلغ والعملة مع ثواني قبل تفعيل الوصول؛ ولا يعتمد على رجوع المتصفح وحده. أضف المفاتيح والأسعار مباشرة في Environment داخل Render ولا ترسلها في GitHub أو المحادثات.

على Render، ضع متغيرات البيئة من لوحة إعدادات الخدمة، ثم أعد النشر. لا تضع مفاتيح API أو كلمات مرور حقيقية في ملفات GitHub العامة.

## البيانات
ينشئ الخادم مجلد `data` تلقائياً ويخزن فيه قاعدة البيانات والصور وسجل العمليات. فعّل قرصاً دائماً (Persistent Disk) في الاستضافة إذا أردت الاحتفاظ بالبيانات بعد إعادة تشغيل الخدمة.

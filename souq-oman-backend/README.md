# سوق عُمان – السيرفر + الموقعان

ثلاثة أجزاء في مجلد واحد، بدون أي مكتبات خارجية (يلزم Node.js 18 أو أحدث فقط):

| الجزء | الرابط | الوظيفة |
|---|---|---|
| موقع المستخدمين | `/` | تصفح، بحث بالكاميرا، إرسال إعلان أو صفحة متجر للمراجعة |
| لوحة المطوّر (موقع منفصل) | `/admin` | قبول أو رفض الطلبات، إضافة متاجر مباشرة، حذف، سجل العمليات |
| السيرفر | `/api/...` | حفظ البيانات والصور وتسجيل كل عملية |

## التشغيل
```bash
ADMIN_PASSWORD='كلمة-مرور-طويلة-وسرية' node server.js
# ثم افتح  http://localhost:3000  و  http://localhost:3000/admin
```
متغيرات اختيارية: `PORT` (3000) · `ALLOWED_ORIGINS` (نطاقات تسمح بالوصول إلى الـ API إن استضفت أحد الموقعين على نطاق آخر، مفصولة بفاصلة) · `TRUST_PROXY=1` (عند الاستضافة خلف وسيط مثل Render/Railway/Nginx ليُسجَّل عنوان IP الحقيقي).

## أين تُحفظ البيانات؟
- `data/db.json` الإعلانات والمتاجر وحالة كل طلب.
- `data/uploads/` صور الإعلانات.
- `data/audit.log` سجل كل عملية (إرسال، قبول، رفض، حذف، دخول ناجح أو فاشل) مع الوقت وعنوان IP.

خذ نسخة احتياطية من مجلد `data` بانتظام. على الاستضافات التي تمسح الملفات عند إعادة التشغيل (مثل الطبقة المجانية في Render) اربط المجلد بقرص دائم Persistent Disk، وإلا ضاعت البيانات.

## الأمان
- كلمة المرور من متغير البيئة فقط، والسيرفر لا يعمل بدونها. جلسة المطوّر تنتهي بعد 12 ساعة.
- حد لمحاولات الدخول (8 كل 15 دقيقة) وحد لإرسال الطلبات (10 في الساعة لكل IP).
- يُتحقق من كل المدخلات في السيرفر، وتُفحص الصور (JPEG/PNG/WebP، أقل من 400KB).
- فعّل HTTPS عبر الاستضافة، فبدونه تنتقل كلمة المرور دون تشفير.

## الحدود الحالية
التخزين بملف JSON يكفي لمئات أو آلاف الإعلانات. إن كبر الموقع فالخطوة التالية قاعدة PostgreSQL.
